# OrbitFabric GitHub Release Source 0.1.0

**Published:** 2026-09-25 as [GitHub Release v0.1.0](https://github.com/OrbitFabric/orbitfabric-github-release-source/releases/tag/v0.1.0).

The first publicly published package of OrbitFabric's provider-specific GitHub Releases acquisition capability. Core [v1.4.0](https://github.com/OrbitFabric/orbitfabric/releases/tag/v1.4.0) composes this provider for exact-release public adapter onboarding. No PyPI publication is assumed.

## Capabilities

- Resolve exact releases selected through the Core-owned, provider-neutral Catalog model.
- Fetch a GitHub Release Descriptor and its descriptor-owned artifact and verify exact identity, expected descriptor digest, artifact size and SHA-256.
- Return the existing Core `ResolvedAdapterRelease` handoff without acquiring ownership of adapter lifecycle or acceptance.
- Offer the explicit `orbitfabric-github-release-source resolve` and Project-Lock-driven `ensure` CLI paths, preserving `MATCH -> NOOP` before Catalog/provider contact.
- Retain GitHub metadata as provider facts, not proof of publisher identity, trust or endorsement.

## Compatibility and evidence boundary

Core owns Catalog selection, Project Lock / Adapter Manager lifecycle, Installed Adapter State and acceptance. This product owns GitHub binding interpretation, acquisition and verification. It does not define a generic source-provider interface, registry or version resolver.

The repository's historical F Prime public-release Consumer CLI E2E is a specific exercised regression lane, not proof of a separate post-publication greenfield replay of the coordinated Core 1.4.0 + GitHub Release Source 0.1.0 + F Prime Adapter 0.1.3 onboarding path. Published products do not automatically promote the Core-owned adapter lifecycle and integration contracts from candidate maturity.
